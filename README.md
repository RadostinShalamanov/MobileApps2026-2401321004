## Описание на идеята

PlantCare е Android приложение за следене на поливането на стайни растения. Потребителят записва растенията си с име, вид, снимка и интервал на поливане, а приложението показва кои имат нужда от вода днес и кои закъсняват.

## Как работи

Добавяш растение с име, вид и интервал на поливане в дни. При запис приложението отбелязва днешния ден като последно поливане и изчислява следващото: последно поливане + интервал. Всяка карта в списъка показва „Полей днес!“, закъснение или колко дни остават. С бутона „Полей“ отбелязваш поливане, с докосване на картата редактираш растението, а с плъзгане настрани го изтриваш (има „Отмени“). Данните се пазят в Room и оцеляват след рестарт.

### Основни функционалности
- **CRUD операции:** добавяне, преглед, редакция и изтриване на растения
- **Изчисляване на поливането:** чиста логика в `WateringCalculator`, покрита с unit тестове
- **Camera Intent:** снимка на растението със системната камера (чрез `FileProvider`)
- **Share Intent:** споделяне на кратък текст за растението към други приложения
- **Material 3:** светла и тъмна тема, която следва настройката на устройството
- **Persistent storage:** Room база данни `plantcare.db`

## Архитектура

Приложението следва **MVVM** с **Repository** слой и **Hilt** за Dependency Injection.

```
bg.uni_plovdiv.fmi.plantcare/
├── data/
│   ├── Plant.kt              # Room entity
│   ├── PlantDao.kt           # заявки към базата
│   ├── AppDatabase.kt        # Room база данни
│   └── PlantRepository.kt    # единствен достъп до данните
├── di/
│   └── DatabaseModule.kt     # Hilt модул
├── domain/
│   ├── WateringCalculator.kt # изчисления за поливането
│   └── PlantValidation.kt    # валидация на формата
├── ui/
│   ├── PlantListFragment.kt  # списък
│   ├── PlantListViewModel.kt
│   ├── PlantAdapter.kt       # RecyclerView адаптер
│   ├── PlantEditFragment.kt  # добавяне и редакция
│   └── PlantEditViewModel.kt
├── util/
│   └── ImageUtils.kt         # зареждане и запис на снимки
├── MainActivity.kt           # Navigation host
└── PlantCareApp.kt           # Hilt Application
```

Поток на данните: `Fragment → ViewModel → PlantRepository → PlantDao → Room`.

## Потребителски поток

1. Приложението стартира и показва списък с растенията (или съобщение, че още няма).
2. Потребителят натиска бутона **+** за ново растение.
3. Попълва име, вид и интервал на поливане, по желание прави снимка и натиска „Запази“.
4. Растението се записва в Room и се появява в списъка със статус за поливане.
5. От списъка потребителят може да:
    - натисне **Полей**, за да отбележи поливане днес;
    - докосне картата, за да редактира растението или да го сподели;
    - плъзне картата настрани, за да я изтрие (с възможност за „Отмени“).
6. При следващо отваряне на приложението всички данни са запазени.

## Инсталация и стартиране

### Предварителни изисквания
- Android Studio (последна стабилна версия) с JDK 17 или по-нова
- Android SDK API 24+ (минимум) и API 35 (target)

### Стъпки
1. Клонирай репото:
```bash
git clone https://github.com/RadostinShalamanov/MobileApps2026-2401321004.git
```
2. Отвори проекта в Android Studio.
3. Изчакай Gradle sync.
4. Стартирай конфигурация `app` на емулатор или реално устройство.

Приложението не ползва API ключове и работи без интернет.

- Монстера – вид „Monstera deliciosa“, интервал 7 дни
- Кактус – интервал 14 дни
- Фикус – интервал 1 ден (за да видиш „Полей днес!“, смени датата на емулатора с един ден напред)

## Тестване

Проектът включва:
- **Unit тестове** за `WateringCalculator`, `PlantValidation` и `PlantRepository` (с фалшив DAO)
- **1 UI тест (Espresso)** за основния сценарий: добавяне на растение и появата му в списъка

Изпълнение на тестовете:
```bash
./gradlew test                    # Unit тестове
./gradlew connectedAndroidTest    # UI тест (нужен е емулатор)
```

Проектът има и **GitHub Actions** workflow (`.github/workflows/android.yml`), който при всеки push пуска unit тестовете и прави debug билд.
